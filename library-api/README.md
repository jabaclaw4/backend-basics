# Library API

OpenAPI 3.1 контракт для сервиса «Библиотека». Описывает управление книгами, читателями и выдачами.

## Ресурсы
- **Books** — управление книгами (CRUD).
- **Readers** — управление читателями (CRUD).
- **Loans** — выдача и возврат книг.

## Как посмотреть документацию
1. Откройте [Swagger Editor](https://editor.swagger.io).
2. Скопируйте содержимое файла `openapi.yaml` и вставьте в левую панель.
3. В правой панели отобразится интерактивная документация.

## Особенности
- Единый формат ошибок `ErrorResponse`.
- Пагинация, фильтрация и сортировка для коллекций.
- Защита от повторной выдачи через `Idempotency-Key` на `POST /loans`.
- Авторизация Bearer JWT (бонус).
